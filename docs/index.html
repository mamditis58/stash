Working local experiment

Authentication playground

What actually happens when you log in? This small Node.js app follows a password from registration to verification, then follows a session cookie through protected requests and logout.

Includes salted password hashing, expiring sessions, CSRF checks, and automated HTTP tests. Accounts reset when the server restarts.
